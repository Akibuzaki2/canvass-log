Extra house outlines for the Treasure Valley (Caldwell to Boise) that OpenStreetMap hasn't drawn yet.
Microsoft ML building footprints from the Overture Maps release 2026-09-23.0 (ODbL), one file per z14 map tile.
Each file is a list of rings; a ring is flat [lat, lng] pairs in millionths of a degree, the first absolute and the rest as deltas.
